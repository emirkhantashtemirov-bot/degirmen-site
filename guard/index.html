🛡️ Degirmen Защита

Приложение для планшетов точки: постоянно сообщает их место. Если планшет унесут с точки или выключат, админу придёт тревога в Telegram, а на карте будет видно, где он.

Скачать APK (Android)
  1. Нажмите «Скачать», откройте файл. Если Android спросит, разрешите установку из этого браузера.
  2. Откройте «Degirmen Защита» и введите 6-значный код: его даёт админ в приложении Degirmen → Касса → Устройства → Где планшеты → «Добавить планшет».
  3. Нажмите все кнопки разрешений: местоположение, «Разрешить в любом режиме», батарея без ограничений.
  4. Samsung: Настройки → Батарея → Ограничения фона → «Никогда не переводить в режим сна» → добавить «Degirmen Защита». Xiaomi: включите «Автозапуск».
  5. Включите «Найти устройство» от Google: он поможет, даже если это приложение остановят.
Приложение не скрывается: на планшете всегда видно уведомление «Защита включена». Только для планшетов Degirmen Navoi.
