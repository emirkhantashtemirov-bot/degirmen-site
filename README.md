# Degirmen Защита
Android-приложение для планшетов Degirmen Navoi: постоянно отправляет местоположение в базу Degirmen, тревога в Telegram, если планшет унесли с точки или он пропал из сети. Видимое уведомление «Защита включена» на планшете всегда, приложение не скрывается.
APK собирается GitHub Actions при пуше в ветку android-tracker и кладётся в ветку apk-out.
